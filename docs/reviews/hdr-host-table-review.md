# HDR宿主查表路径独立审查

日期：2026-10-13。结论：本轮静态证据支持1024项表、所追分支的归一化线性采样、92字节常量上传及宿主启动函数之间的连接。两项浮点精度问题已经修正，当前没有未关闭的P1/P2。完整曝光算法、UI到宿主标量的映射及本次渲染实际执行路径仍未证明。新增原生测量帧为0，既有正式测量42帧的数量没有改变。

## 审查范围

只读检查[研究报告](../research/hdr-host-table-path.md)、[公开证据清单](../experiments/hdr-host-table-evidence.json)、清单中的局部反汇编、导入/展开信息、私有均值探针及其结果。独立读取固定Resolve.exe副本的少量PE字节，复核导入目标、关键实参、映射数组及数值常量；用自写JavaScript标量计算复核数值摘要。另运行一个不接触目标的NumPy标量除法反例。

未启动Ghidra、Resolve或MCP，未执行目标EXE/DLL、SDK或GPU代码，未修改工程、配置、目标文件或主任务脚本。没有重新计算整个目标的大文件哈希；目标身份依据已有固定摘要和本轮局部字节对应性。此审查不是原生实验重跑，也不是全程序调用链或全部数据库函数范围的审计。较早注册入口的详细独立记录另保存在Git忽略的私有目录。

## 静态证据复核

- 通过原始`FF25`间接跳转、对应IAT槽和按名称导入项，确认注册、符号上传、启动配置、`cudaLaunchKernel`及`cudaCreateTextureObject`的目标。注册的float宿主stub对应先前提取的设备符号。常量上传实参为已注册的宿主符号、92字节、偏移0；宿主符号地址不是已取得的设备地址。连接证明的是代码中存在这条路径，未观察某次测量渲染执行它。
- 参数打包把同一源对象偏移117的字节零扩展到上传结构偏移16，同一条件引用`HDR_USE_GAIN`字串；源偏移112位于首16字节拷贝中，对应结构偏移12。这些是字段传递关系，没有补证UI零档/非零档与开关或宿主标量的完整映射。
- 资源列表、sampler构造和启动实参的顺序支持第一项纹理的静态关联。所追CUDA分支的参数栈值经原始字节核对；过滤映射数组为`[0,1]`，寻址数组为`[3,1,2,0]`。本机CUDA 12.8头文件支持过滤值1为Linear、寻址值1为Clamp及描述符字段偏移。该调用配置将前两个寻址槽设为Clamp、第三槽保留0，归一化坐标为1。不能概括为所有纹理、所有后端或三个维度均为Clamp。
- 生成循环、资源尺寸实参均支持1024项。步长原始位型`0x3c802008`为`float32(16/1023)`，坐标偏移常量为8；第一表包含源对象偏移48的全局加数及逐项分区贡献。存在后续修正与平滑，不支持把未平滑端点直线直接称作完整原生表，也未取得本次实验上传的表内容。
- 平滑调用比例原始值为`float32(0.1)`；真实导入为`ceilf`。1024项下窗口为103、半径51，边缘使用缩短的对称范围。关键指令将表中的float32值转为double，使用double加减、除法，再转回float32写入。反编译器的float类型推断不足以反驳这组原始指令。

## 已关闭的问题

**P2：把逐步float32累加当作静态后处理。已关闭。** 原始边缘和内部循环均使用double累加；最初`sliding_sum_f32`模型逐步舍入，不能用其较大残差评判真实后处理。修正后新增double累加候选，旧模型作为被否定的精度候选保留，没有覆盖失败历史。

**P2：double累加候选的分母仍触发float32除法。已关闭。** 本机NumPy 2.4.6中，Python `float / np.float32`返回float32，因此旧写法在除法前又将累计值舍为float32。例如`1.00000007 / np.float32(3)`与double除后再转float32结果不同。原始机器码使用double除法。修正为按模式使用`cast(window)`后，double模式的分母也是Python float，最终才转float32。

修正探针源码原始SHA-256为`b15a4118e43edb5c9c0a6e2aeb3337a36b0ea30b9951c17a6041530bda5e32e1`，结果为`b7b6a06357559eeb1928e7883b0b1b2ba95f546c1e175420326ff84eba1d000c`。独立标量计算遍历六组非零观察、两种插值权重，共576个预测通道；核对24项max/RMSE摘要，最大绝对差为`8.470329472543003e-22`。旧+1的最大误差为：理想插值`9.889709237542732e-6`、最近1/256权重`1.383666187382282e-5`。公开摘要与修正结果一致。

这些数字只检验同一48通道、冻结传递函数/亮度假设下的事后候选。它们没有消除剩余残差，也不是GPU逐位仿真、盲测或新图像验收。均值处理的静态精度得到纠正，不等于其他颜色变换、设备算术和运行资源均已还原。

## 方法与证据边界

直接读取展开记录，确认浮点上传路径后两个区间的`CHAININFO`均指回前段。单个`.pdata`区间不能当作独立函数或完整控制流范围。当前局部脚本显式设置所选函数body，修正过的合并范围有支持；本审查仍未审计所有相邻函数或全部控制流。初次越界探查的重叠错误、早先REA整文件超时属于保留的失败证据，不能因批处理退出0而算作成功。

公开清单列出的12份私有artifact原始哈希均与实际文件一致，本机纹理类型头文件摘要亦一致。公开材料没有复制完整私有反编译代码或将其移入OpenCut实现。当前无需为继续有界静态研究阻断提交；若后续升级为实现或公式复现结论，应另行补证：UI参数到宿主G及零档开关、实际运行资源与kernel/cubin选择、完整分区状态、工作颜色变换、边界行为，以及未见混色/空间样本。现有静态支持不能填补这些缺口。
