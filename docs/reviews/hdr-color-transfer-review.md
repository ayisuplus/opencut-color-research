# HDR颜色转换链：独立审查

日期：2026-10-13。静态方法、构造/注册、分支数学及后验数值经过独立审查，无未解决P1/P2。此结果不等于完整HDR曝光公式通过。

- 方法审查核对四类RTTI/COL主表、三个接口槽和Win64参数。两个wrapper的CHAININFO片段按232/222条完整listing读取，未采用旧125/126条片段；矩阵是36字节launch参数数据，不能写作设备矩阵指针。
- 构造/注册审查以原始字节复核HDR宿主属于所查float类的主表偏移0x10，即零基槽2。成功分配、正常返回及没有后续替换时，+0x60保存所查颜色转换实现。四个stub、完整NUL符号、注册调用和唯一PTX入口匹配；不证明真实实例或实际后端选择。
- Gamma转换的类别倍率由helper返回1或100及caller相乘/相除关系核对，得到1、100或单精度1/100。相同Gamma和非空参数包另有路线，本后验模型没有覆盖所有路线。
- 数学审查核对默认方向0/非0的转换顺序、枚举0/5/6的阶段行为、倍率位置与按行矩阵运算。原生阈值、float32指数、近似指令、FTZ、FMA、NaN的unordered判断保留；这些变换不能宣称逐位精确互逆。
- 独立数值程序使用标量math/struct，不导入或执行主分析器。956项检查通过，覆盖18行、864通道预测、36统计，最大差2.22044604925e−16；只比较理想参考数学，不执行Resolve、GPU或目标PTX。

sRGB理想表两档残差3.72704e−6/7.01221e−6复算成立。矩阵的实数消去不消去q的亮度权重假设；枚举0的幂消去也不能代替实际GPU算术。数值改善没有被升级成真实枚举、矩阵或后端的运行证据。
