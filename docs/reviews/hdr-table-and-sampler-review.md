# HDR表与采样：独立审查

日期：2026-10-13。两名既有审查代理分别完成空分区第一表静态审查和自有CUDA数值审查，无未解决P1/P2。通过只覆盖下述证据与条件，不表示完整曝光公式验收通过。

## 第一表静态条件

审查核对构造器的空vector、两份零贡献表、实际PE常量与CRT导入、修正门、端点加G的操作顺序及返回前地址别名。零贡献下的两方向2046次增长比较用独立模型检查，未执行目标CRT。近零/符号门不调用修正helper；末尾6500相关处理只写第4、5表。第一表仍经过double累加/除法、float32输出的103点均值。

该结论需要实际包集合只含类型0；grade名称、显式类型/启用覆盖、最后类型0写入者及运行内存绑定仍有边界。特殊值、非空分区、其他表与设备采样不在此证明范围内。

## 自有CUDA数值

另一代理没有执行主分析脚本，而以独立标量程序重建7张曝光表、ramp、32个已有颜色坐标及所有诊断点，核对输入42160字节、输出75024字节、源文件/构建副本/可执行文件与运行回执。输入输出均为自有探针资源。构建配方和产物关联已核对，未进行第二次编译来宣称可复现构建。

6261项检查通过，最大独立计算差3.33066907388e−16。2344个ramp输出逐点精确匹配nearest half-up；768个中点保持真实halfway，其中384个与ties-to-even不同。7张FLOAT曝光表相对量化权重表达式仍有GPU舍入差，不能把ramp结果当成所有表的逐位插值公式。

12组后验候选的576个RGB预测与统计全部独立复核。混色+1的GPU查表加CPU变换候选最大差1.88347815939e−5，未恢复完整公式。NVIDIA资料只支持坐标与权重精度约定；中点舍入按本次测量表述。

原混色冻结SHA256仍为`9cb32be3c50b6e0f5342259fa18669f6dcc745439eb8cccb5b9dabc490b892aa`，生成器未改。没有新增Resolve帧，没有修改本轮观测前预测。
