# 白点适配与 GPU 对照独立审查

日期：2026-10-13。审查者分别独立检查固定研究副本的矩阵/上传路径、自有输入和已有输出，不运行目标、Ghidra 或 GPU，不修改历史冻结。

- 默认工作矩阵：47 项静态检查；默认色度、适配调用、double 100、逆端独立求逆及 F32 按行打包得到支持，实际运行分支未绑定。
- 适配结构与核心：37 项检查，另增量核对行优先迭代器与 double 材料化。B 的全部九项是 C 精确逆的四位小数圆整，同白点不能推导单位矩阵。
- 新输入：101 项检查，用有理数独立求解/求逆重建 18/18 个 F32 载荷；仅矩阵区域实际 32 字节变化，原表、像素、程序和历史证据保持。
- 新输出：1238 项检查，独立解析 1152 个 RGB 预测，48 个统计量最大复算差 2.1176e−22；1920 个控制 trace 和 1152 个工作 RGB 值逐位不变。sRGB 的完全匹配仅有 96 个采样通道。
- 上传：R32F、4096 字节 staging 和 sampler 条件路径成立；增量独立解码确认当前分配高 1、宽 1024、flags 0，以及 `cudaMemcpy2DToArrayAsync` 的 4096 字节 pitch/宽、高 1、H2D 和首 plane 句柄。遗漏的分配器跳表块另用原始字节核实当前分支；自有高 0 一维 array 与静态高 1 资源不能直接等同。cache-hit 和其他 provider/storage/adopt 分支未闭合，实际运行未捕获。

输入预审指出旧 GPU 输出使用前缺少显式摘要/布局门，分析器已加固定 SHA、大小和头校验，输出复审确认关闭。报告初稿将工作域与返回域的幂指数 p/a 标反，最终审查指出 P2；已对照自有 CUDA 源码改为工作 p≈0.4166666667、返回 a≈2.4。静态抽取不完整、Java 归档命名错误和审查地址纠正均保留原始回执；修正材料与结果按摘要绑定。

本轮数学及输入/输出范围内无 P1/P2。验收只覆盖固定条件模型和已有有限样本；没有实际 Resolve 矩阵/表/后端见证，没有新增原生帧，没有完整公式或产品验收。矩阵同时改变 Y 与往返，不能单因归结残差改善。
