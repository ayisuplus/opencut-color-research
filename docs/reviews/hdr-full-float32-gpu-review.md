# 完整float32 GPU参考：独立审查

日期：2026-10-13。审查范围为自有程序、冻结输入、一次GPU输出与后验分析；完整Resolve曝光公式未验收。

输入独立检查2463项通过。两张表的2048个float32值由独立均值重建逐位一致；公开xy/D65矩阵及逆由Fraction独立求解，18个存储float一致。三份既有来源、144个中性RGB输入、gamma假设0/0/5、9052字节布局和八模型排序核对。矩阵模式同时改变Y权重和矩阵往返，不是单因素的矩阵精度测试。

代码审查检查CUDA分配、复制、texture创建、同步、释放及输出索引，未见执行阻断。初次编译失败没有GPU运行；修复不存在的函数名和静态断言说明后，旧源与冻结保留，新输入逐字节相同。自有单条指数指令包装保持数学用途；显式FMA顺序和编译参数不能替代目标逐指令或阶段间舍入证明。

输出主复核8579项通过，覆盖3840个有限trace值、2496个原始浮点位不变量、192个软件插值独立F32结果、1152个RGB及24行48项误差统计。RGB与公开数据完全一致；统计最大差2.11758236814e−22。分析器补充预测变化统计及构建绑定后，最终版本另有1242项检查通过，新统计差为0。检查器没有独立重编译或重跑GPU；交叉计算容差不是原生公式验收标准。

前轮结果、三个历史输入及混色观测前冻结保持。软件F32仍有约1e−5原生残差；纹理的xy路径改善混色却恶化sRGB最大误差，无一致胜出的解释。输出中的小负值保留（最小−2.09703e−7），没有裁去后声称一致，也不把它当作原生负输入验证。

本机自有CUDA运行不证明Resolve采用CUDA、对应目标入口、同一数值矩阵或纹理配置。固定假设的后验试验没有拟合参数；实际运行绑定、其他精度顺序、其他枚举和边界仍未知。本轮新增Resolve帧为0，总数48。
