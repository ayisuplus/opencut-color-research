# HDR曝光：Global标量来源与精确零开关

日期：2026-10-13。新增原生渲染0帧，正式测量仍为42帧。本轮仅分析固定研究副本，没有操作达芬奇工程。

此前表生成器中的全局加数G，现已追到HDR参数键`0x86000305`所取出的对象：在所追默认Global类型路径中，名为`GAINJZ`的float32字段原样传入G，没有中间倍率或指数换算。精确零与正常有限非零值对曝光开关的贡献也已区分。**这是静态数据流证据；尚不是完整UI换算、文件反序列化或某次原生渲染执行路径的证明。**

## 名称、类型和数值如何连接

1. 上游处理函数读取键`0x86000305`，经过有效性检查及分支处理后，将对象中的gradeable映射复制到局部映射。映射复制中的节点写入确定的RTTI虚表，类型名为`VaCommon::HDRZoneGradeableKeyframeableParams`。
2. 节点的值对象从偏移88开始；其偏移8对应节点偏移96。该类的名称读写方法把这一字段关联到`GAINJZ`。节点复制以32位搬运保留该字段；名称方法并非本轮已经证明的protobuf反序列化入口。
3. 分区构建器读取节点偏移96到浮点实参，初始化52字节参数包的第一个float。名字表将`Global`映射到枚举6，默认参数表将枚举6映射到内部类型0。这里是两套不同枚举，不能把6和0直接混用。
4. 类型0参数包的52字节被直接复制到HDR对象偏移48，首float就是此前查表生成器的G。该传递段没有乘除、对数或指数运算。

结论限定于所追路径：构建器只遍历输入映射中实际存在的条目，空映射或缺少Global时不会由它自动补出Global包。显式node参数存在时，可以提供类型和启用状态；禁用的条目不进入参数包列表。因此不能仅凭名称为Global，就断言任意工程状态都使用默认类型0。上游还存在参数选择/有效性处理，本轮没有将全部分支与实际实验工程逐一绑定。

未知分区名查不到默认记录时，也会回退到类型0且默认启用。每个类型0包都覆盖对象中的G，因此上述结论首先证明的是Global包在其赋值点的传递；最终G是否仍等于该Global值，还取决于完整包集合、类型覆盖和处理顺序，不能假定Global是唯一写入者。

此前人工确认的精确存储值−1、0、+1分别显示−1.00、0.00、+1.00仍然有效；这三个离散校准点不能扩充为整个UI范围、动画插值或任意显示精度的证明。[原校准记录](hdr-global-parameter-mapping.md)

## 为什么零与极小非零可能走不同路径

参数包初始化时，对首float与零做比较，取反后贡献一个曝光启用位。比较函数中的0.1并不是“曝光绝对值小于0.1则当作零”：它进入相对误差计算，最终阈值约0.001；与零比较时，正常有限非零值的零分母分支会产生FLT_MAX哨兵，因此判为不等。

在这段静态逻辑中，+0和−0不贡献曝光启用位，**任何正常有限非零float32都贡献启用位**，包括已经测过的±2⁻¹⁴和±2⁻¹⁰。次正规值、NaN、Infinity及未观测的MXCSR浮点模式不在这一结论内；界面两位小数显示0.00也不等价于内部精确零。

对象新建时曝光标志先清零，再将每个已进入列表的参数包启用位累积OR。这个OR发生在类型分派之前，并非Global专属。对于正常有限数或带符号零，可以概括该构造过程的曝光标志为：

`gain_enabled = OR(每个已纳入参数包的gainjz不等于精确零)`

所以Global精确为0而其他分区曝光非零时，gain仍可启用。这个标志也不等于整个HDR处理是否启用，黑场偏移、对比度等有其他条件。

此前近零实验观察到：精确零与中性逐位一致，而正负极小曝光有共同偏移。当前找到的开关条件为这种现象提供了结构上相符的解释；本轮没有捕获运行时标志或实际上传表，不能声称已经独立证明了那次像素偏移的全部成因。[近零实验](hdr-near-zero-response.md)

## 对候选公式的更新

若采用默认Global类型路径，且该Global包是最终的类型0写入者，可将此前宿主表表达式中的G绑定为上述Global字段值E：

`T_pre[i] ≈ −8 + 16*i/1023 + E + Z[i]，i=0…1023`

近似号保留float32舍入，Z为分区贡献；生成后的修正与均值平滑仍须保留。若gain启用，此前设备候选分支用工作亮度Y计算`q=log2(clamp(Y,0.0703125,4608)/18)`，以`u=(q+8)/16`查表得t，三个工作通道再共同乘`2^(t−q)`。gain关闭时跳过的是这个查表分支，不能把它概括成整条颜色处理链的恒等变换。

因此，只有另行假定分区贡献为0、理想运算精度和内部采样区间，才能得到条件倍率`2^(E+q/1023)`；这是对候选结构的简化，不是完整公式。原先旧+1样本的约9.89e−6残差没有因本轮字段绑定而消失，也没有重新拟合或新增测量。[表生成、平滑与残差](hdr-host-table-path.md)

## 仍需解决

实际工作颜色变换、全部分区状态、特殊值和边界行为，以及当前实验究竟执行哪个设备分支，都还缺证据。下一步保留现有候选，准备不等幅混色与空间重复的未见输入，检验跨通道和位置依赖；再结合工作颜色转换的静态来源缩小约1e−5残差。当前无需人工操作。
