# HDR 曝光：接近零的响应与非零档参考值

2026-10-13。固定 Resolve 21.1.1.10、005 实验副本、Rec.709 颜色环境和默认黑场偏移，本轮新增六张浮点 EXR，正式实验累计42张。没有更改 Gamma、重开工程或新增人工操作。

## 得到的线索

小正、小负曝光的平均输出与精确零档存在共同偏离；步长缩小16倍，这份偏离没有相应缩小。用小正负档推算一份**样本依赖的非零档参考值**，再按冻结的 BT.709 候选函数乘 `2^E`，可以把旧 −1/+1 样本的最大残差从约 `6.07e-4 / 1.13e-3` 降到 `9.26e-8 / 2.96e-7`。

这把问题收窄到了“非零档参考值如何由输入产生，以及零档为何不同”。仍未得到完整公式：参考值有48个逐样本通道估计量，无法用于任意图像；也未证明数学不连续、内部旁路或真实操作域。

## 固定实验与有效性

执行顺序为存储值 `0, +2^-10, -2^-10, +2^-14, -2^-14`，最后恢复无 HDR 调色的中性状态。两种步长分别为 `0.0009765625` 和 `0.00006103515625`；这里只讨论精确存储值，没有新增 UI 小数或物理 EV 校准。

五份原生 DRX 读回均通过独立严格解析：精确数值保留；零档仅省略默认零标量；其他参数和节点身份一致，黑场偏移参数键缺省。读回的 Body0 `HasCorrection` 始终为 true，Body1 为 false。小步长正负档的 `GetToolsInNode` 返回 None，但原生数值和导出像素确有变化，所以工具标签不能作为是否生效的判据。

每个新任务仅启动自身已记录的 ID，六个任务均 Complete/100%，此前17个任务完整对象保留，最终23个任务均完成。输入与 grade 哈希在各次应用前核对，设置、素材、时间码全程守卫。初始零档和最终中性图的 RGB 与冻结基准逐位相同。终态已保存及备份。五份 DRX 在渲染前抓取；端点一致性并不证明所有中间状态或所有未来执行均相同。

六张图每张6,220,800个通道均通过手工 EXR 解析与 OpenCV 精确交叉核对。全图统计以 float64 计算，另记录16色块中心的48通道以及灰阶/彩色分层；相同色块覆盖大面积，全图像素数量不代表独立样本数量。

## 预先冻结的有限差分

记输出为 `F(E)`，定义偶分量偏移 `C(e)-F(0)=[F(+e)+F(-e)]/2-F(0)`，奇分量 `H(e)=[F(+e)-F(-e)]/2`。下表是全图最大绝对值，数值属于导出 RGB 域。

| 步长 | 偶分量偏移 | 奇分量 | 冻结 BT.709 候选的偶分量偏移（48通道） |
|---|---:|---:|---:|
| 2^-10 | 0.000829935074 | 0.000335037708 | 5.09852e-8 |
| 2^-14 | 0.000829935074 | 0.000020980835 | 1.99161e-10 |

偶分量的全图 RMSE 分别为 `0.000309414798` 和 `0.000309408582`。两组 `H_large - 16 H_small` 的最大绝对差为 `1.847743988e-6`，RMSE 为 `4.930408467e-7`；可描述为大致随步长变化，不能声称严格线性。两点有限差分不能证明极限、导数或跳变阈值，当前也没有测量噪声模型或等价容差。

仅由精确零档出发的候选 `encode709(decode709(F(0))*2^E)` 所预测的偶分量远小于实测偏移，不能直接解释这组数据。候选沿用[冻结的一手函数定义](hdr-exposure-domain-primary-models.md)，没有为本轮调节指数、阈值、黑位或矩阵。

## 事后条件检验：从小非零档推算参考值

这部分在看到本轮结果后设计，独立于上面的预先冻结观测，不伪装成前瞻验证。令 `e=2^-14`：

```text
B = [decode709(F(+e))/2^e + decode709(F(-e))/2^(-e)] / 2
预测(E) = encode709(B * 2^E)
```

只用小步长正负档估计 B，再比较大步长正负档和旧 −1/+1。后三类数据此前已经见过，虽然不参与 B 的数值估计，仍不构成盲测。每个色块每个通道各有一项 B，共48项；这不是从原始像素计算 B 的一般函数。

| 目标存储值 | 从精确零档预测的最大残差 | 从 B 预测的最大残差 |
|---|---:|---:|
| +2^-10 | 8.301005288e-4 | 1.571419660e-7 |
| -2^-10 | 8.296676486e-4 | 1.337063573e-7 |
| 原 +1 | 1.133742271e-3 | 2.961698915e-7 |
| 原 -1 | 6.074872683e-4 | 9.256330435e-8 |

以上仅48通道。小正负档各自推得的 B 最大相差 `3.857065013e-7`；将平均 B 外推到零，仍与实测零档相差最大 `0.000829934874`。B 有6个微负通道，最低 `-1.316998608e-8`，保留原值，沿用候选的线性低段，不进行裁切。未把未选中幂分支的 NumPy warning 当作输出 NaN；所有最终预测均检查有限。

负值和超1值采用冻结候选的代数延伸，不构成 ITU 规范定义域行为的实证。因此“非零档共用某种不同参考值，再随曝光缩放”在这组 Rec.709 样本上具有很强的数值一致性，但 B 的来源未知、零档仍不吻合、残差也不等于零。sRGB 条件此前已有不同响应，不能把这份条件模型直接推广过去。不得据此宣布复现 Resolve、识别某个内部色彩空间，或把48项查表作为产品算法。
