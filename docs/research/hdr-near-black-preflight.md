# 近黑亮度下限：观测前冻结

日期：2026-10-14。阶段 1A。上轮三个未见存储曝光值通过后，本轮仅改变颜色输入，用已测试的 Global −1／+1 检验近黑边界。新原生画面尚未取得，正式 EXR 仍为 54 张。当前达芬奇已由官方接口启动，专用库和 005 源快照有效；当前脚本准入与执行状态以独立回执为准。

旧夹具的非黑色自有模型 q 约为 −2.0163…1.4576，未触及候选下界 −8；黑像素乘有限倍率仍为零，单靠黑无法区分夹紧位置。使用固定适配矩阵、Gamma0 理想指数抵消及 BT.709 低段，灰阶输入的下界约在 U16=207.3473。该解析估计不是实际 GPU 阈值或 Resolve 内部状态；新自有工作值的理想 Y 在 207／208 两块确实跨过 0.0703125。

## 输入与主预测

[准备器](../../experiments/prepare-hdr-near-black.py)生成十六块 1920×1080 PNG16，保持旧夹具的 sRGB intent0 元数据。十五个灰阶码值为 0、1、8、64、128、200、207、208、209、211、256、512、1024、11262、25944；最后一块为旧混色 [11262,25944,45967]。黑和最后三个控制不是新颜色，±1 也不是新曝光校准。

[输入冻结](../experiments/hdr-near-black-input-freeze.json) SHA256 为 `0f573da34d419b9d106bf2ae5df5a9799f4ab45c65c4bd2d61016cfe965a0fc5`。PNG 及全部中心／ROI／全图预期使用事先固定的 `float32(U16) * float32(1/65535)`。独立 PNG chunk／CRC／RGB16／全图解析和输入复算共 2164 项检查通过。

只执行一次既有自有 GPU 程序，源及可执行文件保持，复用两张 ±1 表和 18 个 F32 矩阵载荷。输出 1280 个有限 trace 值；三旧控制、两档、两矩阵、两插值的 240 个 trace 值与此前逐位相同。执行次数依据主任务工具执行记录，不由 metadata 文件数推断。

[预测冻结器](../../experiments/freeze-hdr-near-black-predictions.py)写入[主预测](../experiments/hdr-near-black-prediction-freeze.json)，SHA256 为 `24298e00d3b8b25d3d11c85a7105b3817e33aeea7634a09da1b71d27d628e61c`。八行共 384 个 RGB 预测，观测前主模型固定为适配矩阵＋自有硬件纹理 `[1,0]`，两行／96 个中心通道；其余六行保持为固定对照。预定每通道最大绝对误差门仍为 1e−6，另测每色块 64×64 内部 ROI，每档 196608 通道。独立输出审查 2069 项通过，未拟合或重新挑选模型。

## 夹紧区分诊断

原预测 JSON 的 CPU 无 Y 夹紧诊断与 GPU 主模型还存在精度、矩阵算术、理想插值及 Gamma0 指数消去差别；普通亮度控制也出现大于 1e−6 的差异，不能把全部差异归因于 Y 夹紧。原冻结保留这一结果和限制。

另用[成对诊断脚本](../../experiments/compare-hdr-near-black-clamp.py)固定上述理想 CPU 运算，仅改变 Y 夹紧，单独写[成对诊断](../experiments/hdr-near-black-clamp-diagnostic.json)。两档显著差异只在色块 1–6，即码值 1、8、64、128、200、207；黑、208 及其后全部色块和旧控制差值为零。独立标量复算 279 项通过。它隔离的是共享理想计算条件下的语义差异，不是实际 Resolve 运行证明，也不替代 GPU 主模型或预定误差门。
