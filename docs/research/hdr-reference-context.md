# 同一输入通道为何对应不同的B参考值

2026-10-13。只复算已有16色块及[事后B参考表](hdr-near-zero-response.md)，没有新增渲染或拟合系数。**当前B表不能精确表示成单独的逐通道曲线，也不能只用固定仿射矩阵解释。** 这限定了这张有限参考表的可用模型，并未识别Resolve内部算法。

## 同通道、同数值的对照

灰块6及六个原／间色块的活跃输入通道，PNG16值都为35199，中性EXR编码值都精确为 `0.5371022820472717`。对每个RGB通道分别取具有这个值的四个色块，得到：

| 固定通道 | B的最大值减最小值 |
|---|---:|
| R | 0.00044781426251844225 |
| G | 0.00008570026290088961 |
| B | 0.0007576383474408033 |

例如同一蓝通道：灰块6的B为 `0.29681887353381087`，纯蓝块12为 `0.29606123518637006`。因此，即使RGB各自拥有不同的任意曲线，模型 `B_j=f_j(x_j)` 也不能精确生成这个表：同一个自变量不能同时产生不同结果。这不是仅凭跨通道比较作出的推断。

小正档与小负档各自推得的B，在18组同通道同值比较中的两项估计跨度均不重叠。改用旧±1推算B，与小档参考值相比最大改变 `3.4735721055056956e−7`。这只是推算来源敏感性检查；估计跨度不是置信区间或噪声上界，旧数据也不是盲测。

## 固定矩阵的无拟合检验

主／间色色块的输入可以按分量相加。若B由固定仿射矩阵产生，应满足相应叠加关系；黑块用于抵消常量项。直接计算以下残差，无需估计任何矩阵系数：

| 关系 | 最大绝对残差 |
|---|---:|
| B(青)−B(绿)−B(蓝)+B(黑) | 0.0006958192686497 |
| B(品红)−B(红)−B(蓝)+B(黑) | 0.00039531370486106665 |
| B(黄)−B(红)−B(绿)+B(黑) | 0.00042985591404093304 |
| B(灰块6)−B(红)−B(绿)−B(蓝)+2B(黑) | 0.0007576410450123028 |

固定矩阵前仅各通道独立应用曲线，在这些只有黑／单一活跃幅值的组合上，也须满足同样叠加关系。上述残差排除了它们对当前B表的精确解释，但不排除矩阵与非线性相互交错的复合变换。

## 边界与复算

B仍是选定BT.709候选下估计的48个样本量，不是读取出的内部变量。颜色与色块位置同时变化，尚未隔离颜色上下文和空间上下文；彩色块的活跃通道也仅有一种幅值，不能推断任意混色的规律。因此这里没有证明亮度依赖、特定颜色空间、完整输入变换或像素处理路径。

[复算脚本](../../experiments/check-hdr-reference-context.py)固定原函数版本，并核对B来源哈希；[去身份结果](../experiments/hdr-reference-context-result.json)保留输入值、全部18组对照、叠加残差及来源哈希。结果与先前私有只读复算逐值核对一致。此轮结论不增加正式测量帧数。
