# 未见 Global 存储值：观测前预测

日期：2026-10-13。阶段 1A。此前白点适配修正对已有 −1/+1 样本有较好解释，现在检验同一固定候选能否预测 −0.5、+0.5、+2 三个此前未测试的存储值。颜色夹具仍是旧混色图，只有曝光参数是未见条件；不得将此实验称作未见颜色测试。当前尚未应用新 grade 或取得新原生 EXR，正式测量仍为 48 帧。

## 已冻结的输入与预测

[输入准备器](../../experiments/prepare-hdr-unseen-gains.py)复用前轮固定矩阵、原自有 CUDA 程序和同一个执行文件。输入是原混色 PNG16 的 16 个色块，预先使用 `float32(code) * float32(1/65535)` 归一化，并确认与此前已经核查的中性记录相同；不能看到新中性输出后替换输入。Gamma 枚举固定假设为 0，类别倍率为 1，默认方向、空分区、黑场偏移零及适配矩阵条件保留。

两批表分别为 [−0.5,+0.5] 和 [+2,+1]，后一批 +1 仅作旧自有 GPU 控制。每批含两种矩阵与两种插值；主模型在观测前固定为适配 XYZ 矩阵＋自有硬件纹理 `[matrix=1, interpolation=0]`，不得看完结果改选最好的模型。其他模式保留作固定对照。

输入独立预审 4187 项检查通过：3072 个新表值、1024 个 +1 控制表值、18 个 F32 矩阵载荷及 48 个归一化 RGB 通道均独立复算匹配。已有矩阵、旧源、执行文件、夹具和历史冻结的摘要保持。

本机各批仅运行一次自有执行文件，输出各 5140 字节、1280 个有限 F32 trace 值。旧 +1 的全部 640 个 trace 值与原混色子集逐位相同。随后[预测冻结器](../../experiments/freeze-hdr-unseen-predictions.py)写入[观测前冻结 JSON](../experiments/hdr-unseen-gains-prediction-freeze.json)：12 行、576 个 RGB 预测，其中 3 行／144 个通道属于主模型。冻结文件 SHA256 为 `13b8f6c48c87dc6406fc4d904a79d9e16fd0732dba12392b078a470d9b353862`；程序拒绝覆盖已有冻结。独立输出复核 1291 项检查通过，576 个预测逐项一致；执行次数来自主任务执行记录，不能单凭 run metadata 推断。

预先规定主模型的每个采样/ROI 通道最大绝对误差门为 `1e−6`。这是下一组有限画面对照的区分门，按前轮误差量级保留余量，不是宣称目标公式的物理精度、浮点逐位等价或完整功能通过。+2 主模型最大预测约 1.395，必须使用 RGBFloat EXR 并保留超 1 数值，禁止裁切后再比较。结果须逐档报告完整误差，保留门外结果，不增加逐色块拟合参数。

## 私有调色复制与原生执行门

准备三份独立 grade，只将已核查的 Global float32 存储值从精确 +1 改为 −0.5、+0.5、+2；原源文件保持。独立严格解析确认单 Global、指定四字节变化、其他参数／另一个 Body／外层控制及无另两类 HDR 分支；它们不是 UI 连续映射或物理 EV 的新校准，缺失黑场偏移键也不新增 UI 默认值见证。所有 DRX、解压载体和严格读回仍在忽略的私有目录。

预定六帧顺序：无 HDR 中性、−0.5、+0.5、+2、+0.5 重放、无 HDR 中性恢复。进入渲染前必须完成以下门：

1. 官方接口的版本、专用项目库、项目/时间线/clip/media、完整设置与队列身份读回有效。备份当前 005、保留其 23 个任务；以已有已核查的 006 完成归档导入新隔离副本，禁止覆盖同名工程或源项目。实际执行脚本生成后须独立预审，目前尚未进行脚本准入。
2. 独立严格解析新源 grade，递归 schema、单 Global、float32 位模式、其他参数、另外一个 Body 和外层字节须符合冻结。每档实际原生读回也须严格解析；任何新图结构、未解释参数或其他控制变化都停止，不先渲染再忽略。
3. 第一帧中性必须与冻结的整幅输入归一化规则相同，所有采样、ROI及全图均检查；不符即保留并停止，不更改预测。

原生实际输入/参数门失败和主模型误差门失败分开报告。通过有限样本不能推导所有输入、参数、分区、黑场偏移、异常浮点或 UI 映射均成立。实际运行的矩阵、纹理与后端仍没有捕获；自有一维 array 与此前静态高 1 资源的维度差别保留。
